# Homepage Overview

## Purpose

The Homepage is the user's first impression of Vywee.

It should immediately communicate that Vywee helps users make better buying decisions—not simply find products.

Within 5 seconds, users should understand:

- What Vywee is
- Why it is useful
- What they should do next

---

# Primary Goal

Encourage users to start researching a product using AI Search.

Everything else on the page supports this goal.

---

# Success Criteria

A successful homepage should help users:

- Start a search
- Explore a category
- View trusted recommendations
- Discover buying guides

---

# Primary CTA

Search

This is the most important action on the homepage.

The search bar should remain visible without scrolling on desktop and mobile.

---

# Secondary CTAs

- Browse Categories
- Explore Buying Guides
- View Today's Best Deals
- View Vywee Choice Products

---

# Target Users

- First-time visitors
- Returning users
- Mobile users
- Desktop users

# Mobile Experience

The homepage must be mobile-first.

Priority:

1. Search
2. Categories
3. Vywee Choice
4. Buying Guides

---

# Desktop Experience

Use a wider layout with multiple columns while keeping the search section prominent.

---

# Performance Goals

- Load under 2 seconds
- Responsive
- SEO Friendly
- Accessible

---

# Things to Avoid

- Popups
- Auto-playing videos
- Flashy animations
- Fake urgency
- Cluttered banners

---

# Definition of Success

A new visitor should understand what Vywee does and perform their first search within 30 seconds.
