# AI Search

## Purpose

Search is the heart of Vywee.

Unlike traditional e-commerce search, Vywee Search understands buying intent instead of matching keywords.

Users should feel like they are asking an expert for advice.

---

# Primary Goal

Help users discover the right product in the shortest possible time.

---

# Search Types

Support

• Natural Language

• Product Name

• Brand

• Category

• Budget

• Use Case

Examples

Best laptop under ₹60,000

Best AC for bedroom

Best camera phone

Best monitor for coding
