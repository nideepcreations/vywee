# Design Language

## Purpose

This document defines how Vywee looks, speaks and behaves.

Every page, component and interaction should follow these guidelines.

The objective is to create one consistent experience across the Website, Mobile App and Studio.

---

# Brand Personality

Vywee should feel:

✓ Honest

✓ Intelligent

✓ Helpful

✓ Calm

✓ Premium

Never:

✗ Aggressive

✗ Salesy

✗ Clickbait

✗ Noisy

✗ Overwhelming

---

# Writing Style

Always write in simple English.

Avoid technical words whenever possible.

Example

❌

Authentication Failed

✅

Please sign in to continue.

---

Example

❌

No records found.

✅

We couldn't find matching products.

Try another search.

---

# Button Language

Never use generic buttons.

Instead use meaningful actions.

Preferred

Start Research

Compare Now

View Details

View All Offers

Save Research

Ask Someone

Read Buying Guide

Continue Research

Explore Products

Avoid

OK

Submit

Proceed

Next

Continue

unless absolutely necessary.

---

# Search Placeholder

Always use natural language.

Examples

"What are you looking to buy today?"

"Search products, brands or buying guides"

"Best laptop under ₹60,000"

---

# Empty States

Every empty state should encourage action.

Example

No saved products yet.

↓

Start researching products and save them here.

---

Example

No comparisons yet.

↓

Compare two or more products to see them here.

---

# Error Messages

Never expose technical errors.

Instead of

500 Internal Server Error

Use

Something went wrong.

Please try again.

---

Instead of

Network Error

Use

Please check your internet connection and try again.

---

# Success Messages

Examples

Research saved successfully.

Comparison created.

Buying guide published.

Product imported successfully.

---

# Loading States

Instead of blank screens

Use skeleton loaders.

Show loading only where necessary.

---

# Confirmation Messages

Examples

Remove this product from My Research?

Delete this collection?

Archive this product?

Use clear action buttons.

Cancel

Delete

---

# Tone of Voice

Friendly.

Professional.

Confident.

Never exaggerated.

Never manipulative.

---

# AI Language

Instead of

This is the best product.

Use

We recommend this product because:

• Better battery

• Excellent warranty

• Great value for money

Always explain recommendations.

# Card Design Rules

Every product card must answer

What is it?

How much does it cost?

Why should I care?

What should I do next?

---

# CTA Hierarchy

One primary action.

Maximum two secondary actions.

Avoid multiple competing buttons.

---

# Trust Language

Always explain.

Never exaggerate.

Never create fake urgency.

If uncertain,

say so.

---

# Accessibility

Readable font sizes.

Good contrast.

Large touch targets.

Keyboard friendly.

---

# Motion

Animations should communicate.

Never distract.

Maximum duration

200ms

---

# Overall Feeling

Every screen should leave users thinking:

"I trust this platform."

Not

"This platform is trying to sell me something."

---

# Final Principle

Every word, button and interaction should increase user confidence.

Confidence is the product.

Everything else supports it.
